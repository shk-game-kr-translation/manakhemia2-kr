# 용어집 (마나케미아2 한글화)

## 표기 규칙
- 공백·영문·숫자·문장부호는 ASCII로 입력(빌드 시 반각 글리프로 변환). `…`, `！？` 등 전각은 원하면 그대로 사용.
- 이벤트 대사는 줄바꿈 없이 작성 → 빌드가 13칸 기준으로 단어 단위 자동 줄바꿈(3줄 초과 시 경고).
- 제어코드 `{CLRE}` `{CLGR}` `{CLNR}` `{IM00}` `{=%s}` 등은 원문 순서/개수 그대로 유지.
- 어미: 원문 존댓말/반말 그대로. 말줄임 `…`.
